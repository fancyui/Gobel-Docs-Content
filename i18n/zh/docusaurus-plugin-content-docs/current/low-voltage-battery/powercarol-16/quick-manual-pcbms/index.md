# Gobel PowerCarol 16 快速安装指南

本指南适用于 Gobel Power PowerCarol 16 系列（型号 GP-WP1-16K-PC200B），面向有经验的安装人员，仅列出关键步骤与要点。完整的安装说明、安全须知与故障处理请参见《Gobel PowerCarol 16 安装手册》。

<a id="Quick-Safety"></a>
## 3. 安全要点

:::danger 电击危险
操作前务必断开电池断路器并按 ON/OFF 开关关闭 BMS；断电后端子间可能仍有残余电压，等待至少 10 分钟并用万用表确认无电压后再接线。
:::

:::caution
- 严禁短路正负极端子，严禁反接；严禁串联电池
- 本产品重 125kg，禁止强行单人搬运，禁止侧放和倒置
- 使用绝缘工具，佩戴绝缘手套，摘下金属饰品
- 除厂家授权人员外严禁拆解电池
:::

<a id="Quick-Install"></a>
## 4. 安装

1. **环境要求**：地面平整、承重足够，通风良好，干燥清洁；电池两侧距墙 ≥100mm，顶部 ≥300mm，前方预留 ≥800mm 操作空间。

2. **就位**：利用侧面把手配合底部脚轮将电池移动到安装位置（建议两人配合，防止倾倒），移动到位后锁紧脚轮，用水平尺确认安放水平。

3. **开箱检查**：对照部件清单清点；按 ON/OFF 开机、闭合断路器，用万用表测正负极端子电压，正常应在 **40V ~ 58V** 之间。异常请勿安装，联系技术支持。

<a id="Quick-Wiring"></a>
## 5. 电气连接

### 5.1 接地

按当地电气规范及逆变器的要求，完成电池系统的接地连接。

### 5.2 动力线缆制作与连接

- 自配 50mm² 动力线缆，将线缆穿过储能快插接线端子（02）尾盖，剥线后插入压接铜环底部，用匹配的压线钳压接，再拧回尾盖锁紧
- 线缆另一端按逆变器或汇流排的端子规格压接，并按对应手册要求的扭矩紧固
- 正极端子插入电池正极端子并锁紧到位，另一端连接逆变器电池输入正极；负极同理

:::caution
连接前确认逆变器已关机断电；务必确认正负极对应正确，反接会导致设备严重损坏。压接不良会导致异常发热甚至烧毁，压接后务必逐项检查确认牢固。
:::

### 5.3 通讯连接

- **逆变器通讯**：通讯网线一端接**主机**电池的 RS485A/CAN 端口，另一端接逆变器 BMS 通信接口（RS485 或 CAN 视逆变器而定）
- **室外安装**：连接电池的一端（并联线为两端）须使用 RJ45 防水格兰头（06）和水晶头（07）做防水处理，制作步骤见安装手册"制作防水通讯线缆"章节
- **并联通讯**（多台时）：第一台的 RS485B 接第二台的 RS485C，第二台的 RS485B 接第三台的 RS485C，依次链式连接
- 随附网线为对称线序；若与逆变器引脚定义不匹配，须自制线缆（如 Victron 逆变器），引脚定义见安装手册附录三

:::note
并联地址由系统自动分配（自动拨号），无需手动拨码。
:::

### 5.4 多台并联

- 将每台电池的正负极端子通过动力线与汇流排连接，然后将汇流排连接到逆变器
- 严禁将不同型号、不同规格的电池并联混用

![多台电池与逆变器连接示意图](images/gp-wp1-16k-pc200b-multi-pack-with-inverter.jpg)

:::note
图中实线为动力线缆及汇流排，点线为逆变器通讯线缆，点划线（-.-.-）为电池并联通讯线缆。
:::

<a id="Quick-Protocol"></a>
## 6. 通讯协议设置

多台并联时只需设置**主机**。三种方式任选其一：

1. **电脑上位机**：RS232-USB 通讯线（04）连接 Windows 电脑设置
2. **手机 APP**：USB-Type C 数据线（05）连接手机，在 Gobel Console APP 中设置
3. **Gobel VRM 平台或 APP**：电池接入网络后在线设置

:::note
设置前请先确认逆变器与电池兼容（兼容列表见安装手册"参考文件"章节）。
:::

<a id="Quick-PowerOn"></a>
## 7. 开机

**BMS 开机（ON/OFF 开关）→ 等待自检完成 → 断路器 ON → 逆变器开机**

1. 确认所有线缆连接牢固、区域无人员和异物
2. 按所有电池的 ON/OFF 开关开机，等待 LED 灯条显示正常且无告警
3. 将所有电池的断路器拨到 ON
4. 打开逆变器电源，设置电池类型为锂电池
5. 确认逆变器能正确读取电池数据（电压、SOC、温度等），即可进行充放电测试

:::warning
请勿在断路器闭合之前或同时打开逆变器，不得跳过等待步骤，否则可能产生冲击电流损坏设备。
:::

<a id="Quick-PowerOff"></a>
## 8. 关机

**逆变器关机 → 等待完全停止 → 断路器 OFF → BMS 关机（ON/OFF 开关）**

:::caution
关机后端子间可能仍有残余电压，请勿立即触碰端子。
:::

<a id="Quick-Troubleshooting"></a>
## 9. 常见问题速查

| 现象 | 处理方法 |
| :--- | :--- |
| 逆变器无法读取电池数据 | 检查通讯线连接；核对引脚定义；重设通讯协议 |
| 告警（Alarm）指示点亮 | 排查故障原因，无法解决联系技术支持 |
| 开箱测得端子电压异常（低于 40V 或高于 58V） | 停止安装使用，联系技术支持 |
| WiFi/APP 无法连接 | 参见《WiFi 使用说明书》重新配置 |
| 快插端子连接处异常发热 | 断电后重新插紧端子，必要时重新压接 |

详细故障处理、应急处理及通信引脚定义请参见安装手册附录。
