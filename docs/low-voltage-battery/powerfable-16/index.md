# Gobel PowerFable 16 Product Introduction

PowerFable 16 is a 51.2V 314Ah (approximately 16kWh) LiFePO₄ (lithium iron phosphate) low-voltage energy storage battery from Gobel Power. It uses high-performance 314Ah LiFePO₄ cells, comes in a standard 6U rack-mount enclosure with casters, and is equipped with a high-performance Battery Management System (BMS) for comprehensive battery monitoring and protection. It is suitable for residential and small commercial & industrial energy storage scenarios.

## Key Features

- **High-capacity storage**: Rated capacity of 314Ah (approximately 16kWh), meeting residential and small commercial & industrial energy storage needs
- **Safe and reliable**: LiFePO₄ cells offer stable chemistry and excellent thermal stability
- **Intelligent BMS management**: Real-time monitoring of battery voltage, current, temperature, SOC (state of charge) and other parameters, with multiple protections against over-charge, over-discharge, over-temperature and short circuit
- **Flexible expansion**: Supports parallel connection of up to 63 batteries for easy capacity expansion; the DIP switches support automatic address assignment, so there is no need to set addresses manually one by one
- **Multiple installation options**: 6U standard rack-mount design with casters, supporting rack-mount, stacked (up to 3 units) and floor-standing installation
- **Online monitoring**: Built-in WiFi interface, compatible with the Gobel VRM online monitoring platform, and supports integration with Home Assistant, ioBroker and other platforms
- **Mobile app management**: One-click battery configuration and upgrades via the mobile app
- **Standard interfaces**: Provides multiple communication interfaces including RS485A/CAN (inverter), RS232 (PC/mobile phone) and RS485B/RS485C (parallel connection), compatible with mainstream inverters

## Version Overview

The PowerFable 16 series is divided into two sub-versions by BMS type. Both share the same electrical parameters and installation method, but differ in BMS-related functions (communication protocol settings, host software, mobile app):

| Item | PCBMS Version | JKBMS Version |
| :--- | :--- | :--- |
| Product model | GP-SR1-16K-PC200B | GP-SR1-16K-JK200 |
| BMS type | PCBMS | JKBMS |
| Communication protocol settings | Screen menu / PCBMS host software / Gobel Console APP | Screen menu / JKBMS host software / JKBMS APP |

:::note How to identify the version
Refer to the model number on the product nameplate or panel: a model ending with **PC200B** is the PCBMS Version, and a model ending with **JK200** is the JKBMS Version.
:::
